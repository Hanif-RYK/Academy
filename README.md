# BrightPath Academy – Sample Website

A modern, responsive website for a school, academy or tuition centre (sample project).

**Live demo:** https://hanif-ryk.github.io/Academy/

## Features
- Clean design that works on phone, tablet and computer
- Programs with fees, results, teachers, parent reviews and FAQ
- Admission form that sends the enquiry to the academy's WhatsApp
- "Enroll" buttons pre-select the program in the form
- Floating WhatsApp chat button
- Basic SEO (title, description, social preview tags)
- Fast: a single HTML file, no frameworks

## Customize
Open `index.html` and change the academy name, programs, fees, phone, address and texts.
Set the academy's WhatsApp number in the `WHATSAPP` line near the bottom of the file.
